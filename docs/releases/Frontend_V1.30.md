# Frontend Dashboard V1.30

**Tanggal:** 15 Agustus 2026  
**Status:** Selesai  
**Fokus:** Kalender production, delivery, dan non-duplicated sensor layout

## Diubah

- Quality Context diganti menjadi Production & Delivery Detail.
- Live container berisi enam sensor Kalender: Loadcell Upper/Lower, Temperature Upper/Lower, Dancing Roller, dan Fabric Width.
- Energy dan power dipindahkan ke kartu utama.
- Kartu utama menampilkan Energy Consumption, Power Demand, Output Progress, dan Completed Batches.

## Ditambahkan

- Customer, Fabric Type, Target Grammage, Target Fabric Width, Expected Output, dan Delivery Target.
- Progress bar machine production dengan actual output, remaining output, serta estimasi selesai.

## Batasan

- Seluruh order, delivery, output, dan sensor masih simulated.
