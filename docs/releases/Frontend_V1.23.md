# Frontend Dashboard V1.23

**Tanggal:** 15 Agustus 2026  
**Status:** Selesai  
**Fokus:** Machine electrical consumption per area dan mesin

## Perubahan

- Ditambahkan panel Machine Electrical Consumption pada Utilities.
- Kelompok mesin dapat dipilih antara Jetflow, Calator, Dryer, Kalender, dan Dispensing.
- Pie chart membandingkan energi per area/lane sesuai selected time range.
- Klik area memperbarui ranking power meter mesin pada area tersebut.
- Klik mesin menampilkan energy, actual demand, load, power factor, voltage, dan data status.
- Ditambahkan akses dari meter terpilih menuju detail mesin.
- Target design coverage power meter ditampilkan terpisah dari coverage commissioning aktual.
