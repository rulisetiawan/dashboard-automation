# Frontend Dashboard V1.21

**Tanggal:** 15 Agustus 2026  
**Status:** Selesai  
**Fokus:** Empat kartu PV/SV utama mesin Kalender

## Perubahan

- Empat kartu utama detail Kalender ditetapkan menjadi Loadcell Upper, Loadcell Lower, Temperature Upper, dan Temperature Lower.
- PV menjadi nilai utama pada setiap kartu.
- SV dan unit ditampilkan secara eksplisit pada bagian bawah setiap kartu.
- Jumlah kartu tetap empat sesuai kebutuhan tampilan ringkas.
- Overfeed dan Fabric Width tetap dipertahankan pada area monitoring serta investigasi lainnya.

## Batasan

- Nilai PV dan SV masih simulated dan belum terhubung dengan PLC.
