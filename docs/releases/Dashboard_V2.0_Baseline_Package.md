# Dashboard V2.0 Baseline Package

Paket V2.0 adalah titik awal pengembangan Dashboard V2 yang dipisahkan dari final V1.63.

## Menjalankan Paket

1. Ekstrak ZIP ke folder terpisah.
2. Jalankan `npm install`.
3. Salin `.env.example` menjadi `.env` dan isi koneksi PostgreSQL.
4. Gunakan `PORT` yang berbeda dari V1 apabila kedua versi dibuka bersamaan.
5. Jalankan `npm run start:postgres`.

Paket tidak menyertakan credential, `.env`, `node_modules`, repository Git, atau data import mentah.
