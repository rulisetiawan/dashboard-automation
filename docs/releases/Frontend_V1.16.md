# Frontend Dashboard V1.16

**Tanggal:** 14 Agustus 2026  
**Status:** Selesai  
**Fokus:** Standard full bar chart pada Chemical Processing

## Ringkasan

Grafik Daily Usage by Variant pada halaman detail Chemical Processing disamakan dengan grafik Production Output pada Plant Overview.

## Perubahan

- Grafik chemical menggunakan panel full-width.
- Batang dibuat solid, lebar, dan dimulai dari baseline nol.
- Sumbu Y menampilkan skala konsumsi dalam kilogram.
- Nilai penggunaan ditampilkan di atas setiap batang.
- Warna masing-masing varian chemical tetap dipertahankan.
- Tinggi grafik menggunakan 320 px pada desktop dan 260 px pada perangkat mobile.
- Transfer Route dipisahkan menjadi panel full-width agar tidak mempersempit grafik.

## Batasan

- Nilai penggunaan chemical masih simulated.
- Grafik belum mengikuti custom date range dan belum memiliki drill-down transaksi per varian.
