# Dashboard V1 Concept v1.60

**Tanggal:** 22 Agustus 2026

**Status:** Interactive trend value tooltip

## Ditambahkan

- Seluruh line trend yang menggunakan renderer dashboard bersama memiliki hover pointer.
- Pointer memilih titik waktu terdekat dan menampilkan garis vertikal serta marker pada setiap series.
- Tooltip menampilkan timestamp lengkap, nama series, nilai maksimal dua digit desimal, dan engineering unit.
- Series aktual diberi konteks eksplisit: PV/SV, phase R/S/T, serta metric Motor & Drive.
- Tooltip mengikuti ruang chart agar tidak terpotong pada sisi kanan.

Fitur berlaku pada trend sensor mesin, perbandingan SV/PV, Motor & Drive, dan Historical Trend Explorer.
