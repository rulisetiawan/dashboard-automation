# Dashboard V1 Concept v1.15

**Versi:** 1.15  
**Tanggal:** 15 Agustus 2026  
**Status:** Aktif  
**Fokus perubahan:** Modal Motor & Drive dan parameter tiga fase

## Perubahan tampilan

Klik motor pada detail Kalender membuka diagnostic dalam modal yang terpusat, memiliki jarak aman dari tepi layar, dan dapat ditutup melalui tombol Close detail atau klik area gelap di luar modal.

## Parameter live tambahan

- RMS current fase R, S, dan T.
- Voltage phase-to-neutral R, S, dan T.
- Current imbalance tiga fase serta status balance.
- Ringkasan current dan line voltage rata-rata tetap dipertahankan.

## Prinsip

Tampilan ini mendukung monitoring dan analisa maintenance. Tidak menyediakan kontrol motor, drive, atau PLC.
