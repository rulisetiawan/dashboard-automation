# Dashboard V1 Concept

## Versi 1.9 — Production Order Context pada Kalender

**Tanggal:** 15 Agustus 2026  
**Status:** Aktif  
**Baseline:** Melanjutkan `Dashboard_V1_Concept_v1.8.md`

## Perubahan Konsep

Detail Kalender menyatukan status proses mesin dengan target order yang sedang dikerjakan. Informasi kualitas generik diganti oleh data yang dapat digunakan untuk menilai kesiapan produksi terhadap output dan delivery.

## Prinsip Tampilan

- Data sensor actual dikumpulkan pada satu container live.
- Data energi dan capaian produksi dipisahkan pada kartu utama.
- Target order dan delivery berada pada panel khusus dengan progress bar produksi.
- Nilai yang sama tidak tampil pada lebih dari satu kelompok informasi.
