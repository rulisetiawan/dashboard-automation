# Dashboard V1 Concept

## Versi 1.12 — Click-to-Analyze Motor Drive

**Tanggal:** 15 Agustus 2026  
**Status:** Aktif  
**Baseline:** Melanjutkan `Dashboard_V1_Concept_v1.11.md`

## Perubahan Konsep

Kartu motor pada detail mesin berfungsi sebagai entry point analisa condition dan maintenance. Informasi live, historical, trend, dan maintenance target berada pada satu konteks equipment yang dipilih.

## Prinsip Analisa

- Live Now dan Selected Range dibedakan secara eksplisit.
- Trend historical dapat dipan agar periode panjang dapat diinvestigasi tanpa kehilangan konteks.
- Maintenance recommendation hanya memberi arahan read-only; tidak membuat work order atau mengubah mesin.
