# Dashboard V2 Concept v2.22

**Versi:** 2.22  
**Tanggal:** 28 Agustus 2026  
**Status:** Aktif  
**Baseline:** Melanjutkan `Dashboard_V2_Concept_v2.21.md`  
**Fokus perubahan:** Konsistensi identitas SMM pada sidebar

## Sidebar identity

- Sidebar menggunakan aset logo SMM yang sama dengan halaman login.
- Lockup menampilkan monogram SMM dan nama Sarana Makin Mulya sebagai satu identitas visual.
- Teks merek lama `PT.SMM` dan ikon konektivitas berbasis CSS tidak lagi digunakan pada area brand sidebar.
- Logo tetap terbaca pada lebar sidebar penuh, mengecil secara proporsional pada mode ringkas, dan kembali diperbesar pada drawer mobile.

## Asset consistency

- Aset logo tetap disajikan dari file lokal `/assets/smm-logo-themed-4k.png`.
- Tidak ada ketergantungan gambar eksternal sehingga identitas tersedia pada deployment privat maupun penggunaan lokal.
