# Konsep Dashboard V1

## Versi 1.4 — Declarative Plant Operations Summary

**Tanggal:** 15 Agustus 2026  
**Status:** Aktif  
**Baseline:** Melanjutkan `Dashboard_V1_Concept_v1.3.md`

## 1. Tujuan Pembaruan

Versi ini mempertahankan tujuh informasi management dari V1.3, tetapi mengubah seluruh judul berbentuk pertanyaan menjadi label operasional yang singkat dan deklaratif.

## 2. Label Ringkasan

1. Machine Operating Status.
2. Machine Attention Status.
3. Total Production Output.
4. Current Utility Usage.
5. Total Utility Consumption.
6. Batches In Process.
7. Completed Batches.

Judul section menggunakan Plant Operations Summary. Tidak ada kalimat pertanyaan pada kartu utama.

## 3. Scope Data

- Machine Operating Status, Machine Attention Status, Current Utility Usage, dan Batches In Process menggunakan Live Now.
- Total Production Output, Total Utility Consumption, dan Completed Batches menggunakan Selected Range.
- Tabel status mesin serta perilaku drill-down dari V1.3 tetap dipertahankan.

## 4. Batasan V1.4

- Data masih simulated.
- Klasifikasi Maintenance aktual tetap membutuhkan integrasi CMMS/MES.
