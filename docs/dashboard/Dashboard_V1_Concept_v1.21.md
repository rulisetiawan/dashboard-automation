# Dashboard V1 Concept v1.21

**Versi:** 1.21  
**Tanggal:** 15 Agustus 2026  
**Status:** Aktif  
**Fokus perubahan:** Cross-process Motor & Drive diagnostic

Workspace Motor & Drive tidak lagi terbatas pada Kalender. Jetflow, Calator, Dryer, dan Kalender menggunakan modal diagnostic yang sama, sementara ID mesin induk dan tipe proses tetap ditampilkan agar data tidak tercampur.

Klik motor/equipment pada masing-masing proses membuka data live R/S/T, historical range, troubleshooting, trend, complete log, serta export CSV.
