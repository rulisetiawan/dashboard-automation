## Perubahan Tampilan

Container Live Sensor Measurements dirapikan agar enam sensor mesin lebih mudah dibaca pada desktop dan mobile.

- Panel tidak lagi meregang mengikuti tinggi Parameter Configuration.
- Enam kartu sensor menggunakan grid dua kolom yang konsisten.
- Label sensor, status Good, nilai aktual, dan target memiliki area masing-masing sehingga tidak saling bertabrakan.
- Kartu diberi tinggi minimum dan spacing seragam.

## Batasan V1.5

- Perubahan ini hanya menyempurnakan layout; sumber dan nilai sensor tetap simulated.
