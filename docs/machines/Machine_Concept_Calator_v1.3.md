# Machine Concept Calator v1.3

**Versi:** 1.3  
**Tanggal:** 18 Agustus 2026  
**Status:** Aktif  
**Fokus perubahan:** Penyederhanaan detail monitoring Calator

## Perubahan dari v1.2

Panel **Speed Synchronization** dihapus dari halaman detail per mesin Calator.

Monitoring yang tetap ditampilkan berfokus pada informasi yang lebih langsung digunakan operator dan manajemen:

- Multi-Speed Profile sesuai subtype Standard atau Bianco.
- Overfeed Out sebagai parameter kritis.
- Dancing roller.
- Chemical transfer dan penggunaan chemical.
- Output baik (good output).
- Motor & Drive Diagnostic per equipment.
- Process Run History, batch investigation, trend sensor, dan abnormality log.

## Catatan

Data speed individual tetap tersedia pada Multi-Speed Profile. Penghapusan panel tidak menghapus tag, histori, atau kemungkinan analisis rasio speed pada backend di fase berikutnya.
